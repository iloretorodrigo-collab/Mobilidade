# Painel administrativo

Painel web planejado para operações da plataforma.

## Módulos previstos
- Gestão de passageiros e motoristas
- Revisão de documentos e suporte
- Monitoramento de corridas e incidentes
- Tarifas, áreas de operação e relatórios
- Auditoria de ações administrativas

Este diretório é um placeholder de arquitetura; a interface e as integrações ainda precisam ser implementadas.
