# App do motorista

Aplicativo móvel planejado em React Native + Expo.

## Fluxos previstos
- Cadastro e verificação documental
- Disponibilidade online/offline
- Receber e aceitar solicitações
- Navegação e atualização de status
- Ganhos, histórico e suporte

Este diretório é um placeholder de arquitetura; a interface e as integrações ainda precisam ser implementadas.
