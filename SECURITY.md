# Segurança

- Nunca faça commit de tokens, senhas ou chaves privadas.
- Use variáveis de ambiente localmente e GitHub Secrets em CI/CD.
- Antes de produção, implemente autenticação segura, autorização por função, rate limiting, validação de entrada, trilha de auditoria e política de retenção de dados.
- Reporte vulnerabilidades de forma privada ao mantenedor do repositório.
